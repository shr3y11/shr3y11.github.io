# Shrey — Cybersecurity Portfolio

Source for [shr3y11.github.io](https://shr3y11.github.io), a static portfolio focused on governance, risk, compliance, and practical security engineering.

The site deploys directly through GitHub Pages, with no build step. The résumé overlay lazy-loads a local copy of Mozilla PDF.js (6.3.289, Apache-2.0) when opened. Its license is in `assets/vendor/pdfjs/LICENSE`.

The public résumé uses Jake Gutierrez's LaTeX template and Computer Modern fonts. Its editable source is `assets/resume/shreeyash-wale-resume.tex`. Compile it with pdfLaTeX or Tectonic into `output/pdf/`, inspect the rendered PDF, then replace the public PDF and PNG fallback in `assets/resume/`. The previous ReportLab builder is retired to prevent restoring outdated content. Education and skills are user-confirmed; no formal employment history is claimed. ISO 27001 Lead Auditor completion is user-confirmed; its issuer and award date have not been supplied.
